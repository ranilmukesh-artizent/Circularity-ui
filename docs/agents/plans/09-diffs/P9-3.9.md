# P9-3.9: tool-fleet numbers before and after (wear index and remaining life)

R8. A tool-fleet case opened from data with telematics run hours (`condition.run_hours`, P9-3.2) or months on its contract
(`contract_line.months_on_contract`) now has its remaining life (`rul`) and each part's remaining life (`partRul`)
computed per component by `tool_life.evaluate` (rules `tf-life-1`, table `tf-life-table-1`), instead of the input value the
case came with. The result is kept on the case as `life` (wear index, remaining life with the weakest component, a row per
component, confidence, inputs, table and rule versions) and served at `GET /api/screens/toolfleet/{id}` as `life`.

## The sample world (the prototype's 26 open returns): no change

The sample world has no telematics hours and no contract duration, so it keeps its `rul` and `partRul`; the PO goldens
(`equip_decisions.json`) keep every best path and net (`test_po_golden.py`, `test_valuer_tool_fleet.py`).

## Cases opened from data

| Case | Before | After |
|---|---|---|
| `CMH-48213`: 820 h, 30% high load, piston kit replaced at 500 h, coverage 95, seen 3 days ago | `rul` the input value | `rul` 21 (Motor armature, 223.5 h), `partRul` 21/37/59/39, WTI 65, confidence High |
| the same tool with no telematics, 41 months on contract | `rul` the input value | `rul` 21, range 0 to 53, confidence Low: re-issue and pool are never the recommendation |
| telematics 7 days old or more | `rul` the input value | computed from the hours, confidence Low: re-issue and pool held (as GR-13) |
| coverage under 90, or a replaced component with no hours in the log | `rul` the input value | computed, confidence Medium |
| a case with neither run hours nor months on contract | `rul` the input value | unchanged, no `life` |

A changed `rul` moves the valuer's numbers (refurbish needs 40, re-issue grade B or C needs 40, pool 45, the outlet value
reads it, harvest reads each part's life), so the recommendation of an open case can change. To list the changed cases on a
stack whose `fleet`, `tooltel`, `repairlog` and `windchill` sources have synced: run `python -m scripts.diff_tool_fleet save
<file>` on the code before this commit and again after it, then `report <before> <after> P9-3.9`.
