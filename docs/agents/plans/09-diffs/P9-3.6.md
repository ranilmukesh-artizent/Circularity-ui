lines, and the write of a line queues `case.gateRecheck`, which releases the case when the line clears it.

To list the changed cases with their old and new route and net, on a stack whose `fleet` source has synced: run
`python -m scripts.diff_tool_fleet save <file>` on the code before this commit and again on the code after it (the worker
has run the rechecks), then `python -m scripts.diff_tool_fleet report <before> <after> P9-3.6`.
