The returned tool's journey, and where Recover acts

The customer's experience does not change. Recover acts in the highlighted stages, inside the processes and systems you already run.

  1. Stage 1Tools in use on siteCustomer

    Fleet contract with end dates and swap rights. Recover sees renewal demand 60 days ahead.

    ERP sales · fleet contracts
  2. Stage 2Repair or return requestedCustomer

    Logged in the fleet app or portal. A loaner is promised.

    Fleet app · ERP service
  3. Stage 3Pickup and inboundTool logistics

    Collected and sent to the nearest service center.

    Carrier events
  4. Stage 4Intake and diagnosisIntake + Condition agents

    Technician grade, fault and estimate, plus remaining life and safety rules.

    Repair workbench
  5. Stage 5Best next life decidedDemand, Valuation, Disposition agents

    Six paths priced against named demand: renewals, pool shortages, open repair orders, bids.

    Recover
  6. Stage 6Approved, executed in placeFollow-through agent

    Owner approves. Recover writes the repair order completion, stock transfer, contract line or sales order.

    ERP service · sales · inventory
  7. Stage 7Customer stays productiveCustomer

    Repaired or replacement tool back inside the turnaround promise.

    Fleet app
  8. Stage 8Learn and reportLearning memory

    Actual costs, pass rates and prices retrain the models. CO2 and parts reuse counted per tool.

    Circularity ledger

No rip and replace. Plug and play: the enterprise applications already in place stay the systems of record and execute every action. Recover runs in the client's cloud tenancy, reuses its existing data adapters, and if it is unavailable, returns follow the standard route.

Where the value comes from

Four patterns that repeat every day in a tool service network. Each is a screen in the demo.

Repair centerRepairing a tool for a contract about to endRecover issues it to a renewal that would otherwise wait on new stock.
RemarketingSelling a grade A return while a pool is shortRecover routes it to the short pool and cancels the new-unit requisition.
TechnicianScrapping a tool whose parts are on open repair ordersRecover harvests and certifies those parts against the orders.
Fleet deskTwo returns promised to the same renewalThe queue plan fills each order once, where it adds most.
